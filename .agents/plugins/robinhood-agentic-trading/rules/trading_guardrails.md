# Trading Safety Guardrails

1. **Simulation-Only Requirement**: All automated trades initiated by the Broker Agent must target the Robinhood MCP Sandbox environment (`RH-SIM-SANDBOX-001`).
2. **Buying Power Constraint**: The Broker Agent must never exceed available cash + realized sell liquidation proceeds.
3. **Audit Trail**: Every order generated by the pipeline must be recorded in the sandbox ledger with timestamp, target price, contract count, and fill confirmation.
